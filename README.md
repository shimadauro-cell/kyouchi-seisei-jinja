# 鏡知生成神社

「鏡知生成神社（きょうちせいせいじんじゃ）」は、生成AIを祀る架空のバーチャル神社を題材にした、同人イベント展示向けの静的サイトです。

実在の社寺や宗教団体とは関係のない創作物として、生成AI初心者が気軽に立ち寄れる導線を目指しています。

## 内容

- トップ・世界観紹介（御神体「四央文書」は非公開）
- 胸像を磨く、または32GB DRAM二枚組・RTX 5090を拝して完了する「生成祈願」
- ランダム結果を表示する「生成おみくじ」
- 生成結果に応じた「供養」
- 「手指安定社」の紹介
- 七柱を奉る「破綻供養塔」
- 固定サンプルによる「奉納絵馬ギャラリー」
- イベント会場でのみ実売する「授与品案内」
- 設定資料としての「鏡知縁起」

## ローカル確認

`index.html` をブラウザで開くだけで閲覧できます。外部API、外部フォント、ビルド処理、ログイン・投稿保存機能は使用していません。

## GitHub Pages 公開

すべての参照パスは相対パスです。リポジトリのルートを GitHub Pages の公開元に設定すれば、そのまま配信できます。

1. この構成をGitHubリポジトリへpushします。
2. GitHubの `Settings` > `Pages` で公開ブランチと `/ (root)` を選択します。
3. 公開URLをイベント用QRコードに設定します。

## 授与品について

サイト内に掲載する破綻除御守、電脳御朱印、生成供養札はイベント会場での実売案内を想定したものです。ウェブ通販や予約受付を行う機能はありません。
